# dsh-highschool-tutor

> 面向**高中三年（语文 · 数学 · 英语 · 物理 · 化学 · 地理）**的学习与巩固插件。它把「错题本 + 艾宾浩斯间隔复习 + 知识卡片库 + 学习进度 + 模考趋势」做成一个整体：你在对话里讲完一道错题，模型直接把它写进题库并排好复习时间；到期的题目会变成**对话里的复习翻卡**（你说「抽查我」即可开练），会话标题栏的徽标提醒你今天还有多少条待复习、距高考还有多少天。
>
> 讲**数学 / 物理 / 化学 / 地理**的题目时，模型还会顺手画一张**可交互的动态演示图**——函数切线、立体几何截面、受力分解、电路、分子构型、晶胞、地球光照都能画，配一条**分步解题时间轴**（重点步骤醒目标出，图跟着讲解一步步长出来），可在对话里直接看，也可推到**右侧栏**放大拖着转。

零依赖、零构建：host 半边是普通 ESM，client 半边就是可直接加载的浏览器包，改完刷新页面即生效。

> **想先看效果？** 打开 [`docs/index.html`](docs/index.html) —— 13 份可交互演示的离线画廊，不用装插件。

| **高考倒计时 + 模考趋势** | 按年级自动推算高考日期；单科分/总分/名次录入，画总分得分率趋势 |
| **批量导入导出** | Markdown 问答块、Markdown 表格、CSV、Anki 导出的 TSV；题库可导出为 Markdown |

## 安装

```bash
# 装入 web profile（本地目录形式）
dsh plugin --profile web add /path/to/dsh-highschool-tutor

# 若 pnpm 报 store 位置不一致，补上 profile 当初使用的 store
dsh plugin --profile web add /path/to/dsh-highschool-tutor --store-dir "$DSH_HOME/.pnpm-store"
```

包内 `cordis.patch.yml` 声明了 `dsh.bundle.patch`，安装后会自动并入 profile 的 bundle 层（`dsh.profile.bundles`），**无需手工编辑 profile 的 cordis.patch.yml**。安装完成后**重启 `dsh web`** 让 host 半边挂载，再刷新页面即可看到设置页分区与标题栏徽标。

## 界面

**设置 → 高中助学**（`settings.section`），七个标签页：

- **今日** — 高考倒计时、今日待复习/已复习/学习时长、目标进度条、复习入口指引（复习已搬到对话）、快速记学习时长、薄弱知识点排行（点进题库）
- **题库** — 六科错题/知识卡检索（关键词 / 学科 / 类型 / 状态 / 排序）、展开看答案解析、编辑、删除、新增、批量导入、导出 Markdown、一键导入内置卡片包
- **资料** — 上传 Word 试卷 / PPT 课件 / 粘贴文本 → 预览切题结果（逐条勾选）→ 入库
- **演示** — 已存的动态演示（可搜、可按学科筛）、点标题就地预览、推到右侧栏、删除；下方是九种场景类型的**内置示例**，每种一份真实题目的完整演示
- **计划** — 按待复习量与薄弱程度把每日分钟目标摊到各科、教材章节勾选、最近笔记
- **统计** — 每日复习量（柱）与学习时长（折线）、一次通过率与熟卡保持率、各科掌握度、模考总分趋势与成绩录入
- **设置** — 年级 / 高考日期 / 考区教材 / 启用学科 / 每日目标 / 每日新卡上限、数据目录、对话用法速查

**会话标题栏徽标**（`conversation.session.header.utilities`，位于工具行左侧）：显示「待复习条数」与「距高考天数」，点开是小面板——分学科待复习数 + 一句「在对话里说抽查我开始复习」的指引。默认 60 秒轮询，标签页隐藏时暂停。

### 讲题卡与复习翻卡（对话里的一体化卡片）

讲题时模型调用 `tutor_visualize`，对话里会生成一张**讲题卡**：题目 → 16:9 动态演示画布 → 「显示答案」展开答案与解析 → 四档评分（重来/困难/良好/简单）**直接写入艾宾浩斯排期**。演示被推到侧栏/独立窗口时，题目答案仍完整留在卡片上。

复习时（「抽查我 10 道」「考考我物理」），模型调用 `tutor_review_deck` 把今日到期题打包成**翻卡套组**：一张张翻、一张张评分，「重来」的卡本轮队尾重现；空格翻面、1-4 评分。评分接口 `/api/highschool-tutor/review` 同时被设置页统计与卡片共用。

### 演示显示在哪

四种落点，按「独立窗口 → **better-sidebar 页签** → 自带浮层 → 对话内嵌」优先级自动选择，**同一份演示永远只渲染一处**（同一个场景画两遍纯属浪费）：

| 落点 | 前提 / 怎么进入 | 特点 |
|---|---|---|
| **侧栏页签**（推荐） | 装了 [`dsh-better-sidebar`](https://github.com/omdsh-dev/DSH-better-sidebar) 就自动生效 | VSCode 风格的**真正停靠列**，可分屏、可调宽、按会话隔离；新演示自动切到本页签 |
| **独立窗口** | 卡片/页签上点「独立窗口」（浏览器要求首次必须由点击触发）；左侧栏入口 Shift+点击 | 完全独立于对话页面，**可拖到另一块屏幕**；开着时优先级最高 |
| **自带浮层** | 没装 better-sidebar 时的默认 | 可拖宽 320–760px、Esc 关闭 |
| **对话内嵌** | 以上都没有时的兜底 | 跟着对话流，适合边看边滚 |

演示落在别处时，对话里那张讲题卡会主动让位：画布不再重复渲染，只留标题、摘要、**题目与答案区**及重点步骤芯片（点芯片仍能驱动那边的帧跳步），并标注「正在侧栏页签显示 / 正在独立窗口显示 / 正在右侧栏显示」。

**与 dsh-better-sidebar 的集成方式**：通过它公开的 `ctx.betterSidebar.registerTab()` 注册一个 `highschool-tutor:demo` 页签（单实例、带图标、可在它的设置页开关）。依赖是**可选**的——用 cordis 的 `ctx.inject(['betterSidebar'], …)` 而不是把它写进本包顶层 `inject`，所以没装那个插件时本插件其余功能完全不受影响；服务被卸载（或 HMR 重载）时自动回落到自带浮层。新演示到达时用 `openTab` + `updateTab` 送达；若面板处于收起状态，会先 `closeTab` 再 `openTab`，借宿主对「内容打开」的处理把面板自动展开。

**独立窗口**（`GET /panel.html`）是普通同源页面，不是 iframe：
- 与对话页通过 **BroadcastChannel** 通信，**两边任意一边刷新都能重新握手**——不用 `window.opener`，因为那个引用一刷新就断
- 引擎走 `<script src="./frame.js">` 加载，页面本身只有 6.5 KB
- **也能独立使用**：直接打开这个地址就显示最近一份演示，`?demo=dm_0003` 可指定某一份，顶部还有「最近演示」下拉与「跟随对话」开关
- 自带明暗两套配色，同时接受对话页桥过来的宿主主题

自动推送只对**当场生成**的演示生效：刷新页面重放历史对话时，一堆旧演示不会轮流抢占显示区。判定用两个信号——这次调用是否曾以「运行中」状态渲染过，以及是否已过页面初始重放窗口。侧栏头部的「自动」勾选框可关掉该行为（偏好记在本地），host 侧 `autoDock` 配置提供默认值。

**演示卡片**（`tool.call.toolview`，key = `tutor_visualize`）：标题、场景摘要、**重点步骤芯片**（点一下直接让侧栏跳到那一步），以及画布（仅在未进侧栏时渲染）。内容全部取自该次工具调用的持久化 meta，**刷新页面、会话重放都能重新画出来**。

**右侧停靠面板**（`shell.overlay`）：常驻右侧、可拖左边缘调宽（320–760px，宽度记住）、Esc 关闭；顶部有「自动」开关与「最近」切换（可换到其它已存演示）。选它而不是宿主自带的 details 列，是因为那一列是单占位且已被工具详情占用——挂进去会接管**所有**工具的详情渲染，代价太大。

**左侧栏底部入口**（`sidebar.footer.action`）：常驻的「动态演示」按钮，侧栏关掉后一键叫回来（优先上一份演示，其次库里最新的一份，都没有就打开内置示例）。侧栏折叠成 56px 轨道时只显示图标。

## 电子资料直接入库

把手上的电子试卷、课件、练习题直接变成带复习排期的题库。入口在 **设置 → 高中助学 → 资料**，也可以在对话里说「把这份卷子导进来」（模型调 `tutor_paper_import`）。

### 支持的格式

| 格式 | 支持程度 | 说明 |
|---|---|---|
| `.docx` | ✅ 直接解析 | Word 试卷的主力格式，解析最可靠 |
| `.pptx` | ✅ 直接解析 | 课件，按页转成知识卡 |
| `.txt` / `.md` / `.csv` / `.html` | ✅ 直接解析 | 纯文本自动识别 **UTF-8 / GBK / UTF-16**（中文 txt 常是 GBK） |
| `.pdf` | ⚠️ 需转换 | 先用 Word/WPS 另存为 `.docx` 再导入 |
| 图片 / 扫描件 | ⚠️ 走对话 | 直接把图发在对话里，由模型 OCR 后写入——比先转文字更准，因为模型能同时看懂图和公式 |
| `.xlsx` | ⚠️ 需转换 | 「题干/答案」两列的表格，另存为 CSV 即可 |

PDF 与图片**不做半吊子解析**：带文字层的 PDF 需要解析字体 CMap，扫描版只能 OCR，两者都可能产出看似成功实则乱码的结果。所以这里明确拒绝并给出可执行的替代路径，而不是把脏数据写进要天天复习的题库。

### 试卷解析做了什么

从真实中文试卷的排版反推的规则：

- **大题**：`一、单项选择题（本题共8小题…）` → 题型自动打标（选择题/填空题/解答题…）
- **小题号**：`1．` `1.` `1、` `1)` `１．`（全角）都认；`（1）` `①` 判为**小问**，归到母题而不是独立成题
- **选项**：`A．甲 B．乙 C．丙 D．丁` 挤在一行、分成四行、或**排在 Word 表格里**（表格行会按单元格用制表符连回一行）
- **内嵌答案**：`【答案】B` `【解析】…` 拆到独立字段
- **文末答案区**：识别 `参考答案` / `答案与解析` 等标题，把 `1．B　2．A　3．C` 这类压成一行的答案**按题号回填**到每道题上——这是最有价值的一步，否则导进去的题目全部没有答案，题库也就废了
- **分值** → 难度：`（12分）` 映射到难度 4，并把分值标注从题干里清掉
- **页眉页脚噪声**：`第 3 页 共 8 页`、`- 2 -` 之类自动丢弃

### 为什么一定要「先预览再入库」

切题是启发式的，而题库是每天要复习的东西——脏数据的代价远高于多点一次按钮。所以：

1. 解析后先给预览：切出多少题、多少题匹配到答案、每题的标签与难度，可逐条勾选排除；
2. **可信度闸门**：如果解析结果不像试卷（首题号异常、题号不递增、题干过短），默认**拒绝写库**并说明理由。举个真实例子——`/etc/hosts` 里的 `127.0.0.1` 会被「行首数字 + 点」的规则切成「第 127 题」，没有这道闸门就会静默入库。确认无误后可勾选「仍然导入」（工具侧对应 `force: true`）。

### 课件模式

`.pptx` 抽取时每页留一个 `【第N页】` 标记，转卡时**每页一张知识卡**：首行当正面（标题），其余当背面；只有标题没有内容的过渡页自动跳过。

## 动态演示

### 怎么用

直接说人话即可，模型会自己判断要不要出图：

- 「这道导数题给我画个图」「用图讲讲这题」
- 「正方体里过 A、C、B₁ 的截面是什么形状」→ 立体几何截面，能拖着转
- 「斜面上的滑块怎么受力」→ 受力分析 + 重力分解，一步步出现
- 「NaCl 晶胞里有几个 Na⁺」→ 晶胞图，自动按「顶点 1/8、棱心 1/4、面心 1/2、体心 1」算给你看
- 「夏至日北京的正午太阳高度」→ 地球光照图，自动画晨昏线并算出 73.5°

### 九种场景类型

| 类型 | 用途 | 亮点 |
|---|---|---|
| `plot2d` | 函数图像、切线、面积、圆锥曲线 | 内置表达式求值与**数值求导**——写 `tangent: { of: 'curve', at: 1 }` 就自动画出切线并标出斜率 |
| `geom3d` | 棱柱棱锥圆锥球、空间向量、二面角 | **截面自动求交**：给平面的法向量与过点，引擎算出截面多边形；顶点可标 A/B/C/A₁… |
| `mech2d` | 受力分析、斜面、弹簧滑轮、抛体与圆周 | 力/速度/加速度箭头按大小成比例；轨迹可播放动画；匀强场画 ×/· |
| `circuit` | 电源、电阻、滑动变阻器、电表、开关 | 元件自带引线，`wire` 连成回路即可；开关可画断开态，导线可带电流箭头 |
| `chart2d` | 平衡移动、滴定曲线、能量图、气温降水 | 曲线/柱状/阶梯/散点、关键点标记（自动引虚线到坐标轴）、区间阴影 |
| `molecule3d` | 分子构型与键角 | **按 VSEPR 自动摆位**：给中心原子 + 配体 + 构型名，坐标不用自己算（正四面体 109.47°、V 形 104.5°） |
| `lattice3d` | 晶胞与配位数 | 预设 NaCl/CsCl/金刚石/ZnS/CaF₂/干冰/fcc/bcc/sc，**自动算每胞微粒数**并标在图上 |
| `globe3d` | 地球光照、昼夜、正午太阳高度 | 给直射点纬度，自动算昼夜半球着色、晨昏线、极昼范围，点上可自动标出正午太阳高度 |
| `diagram2d` | 工业流程、锋面、剖面、结构梳理 | 箭头端点可**直接写方框 id**，自动从框边缘出发；文字自动折行 |
| `html` | 上面都表达不了时的兜底 | 直接给 HTML 片段，在沙箱帧里执行（含 `<script>`，无网络） |

### 解题步骤

`scene.steps` 是这套东西的重点。每一步都能改变画面：

```jsonc
{
  "title": "把重力沿斜面方向分解",
  "detail": "关键一步：不要分解 N 和 f，而是把 G 分解到沿斜面与垂直斜面两个方向",
  "formula": "G∥ = mg sinθ    G⊥ = mg cosθ",
  "key": true,              // 重点步骤：时间轴标★、说明区变金色、卡片折叠态也列出来
  "show": ["G1", "G2"],     // 本步开始显示（配合对象上的 hidden:true 做逐步呈现）
  "hide": ["N"],            // 本步隐藏
  "focus": ["G1", "G2"],    // 本步高亮（加光晕）——「这一步看这里」
  "set": { "tan": { "at": 2 } },   // 改对象属性，如把切点移到 x=2
  "view": { "yaw": 62 }     // 转一下相机
}
```

步骤是**累积**语义：第 n 步的画面 = 初始场景依次施加 0…n 步。所以来回点步骤、拖进度条得到的画面完全一致，不会像增量动画那样漂移（这条有专门的回归测试）。`focus` 只取当前步，所以「这一步在看哪里」永远清晰。

界面上：步骤芯片可点，`‹ ▶ ›` 可上一步/自动播放/下一步，键盘 `←` `→` 切步、空格播放、`r` 复位视角；2D 可拖动平移 + 滚轮缩放，3D 可拖拽旋转 + 滚轮缩放 + 双击复位。

### 模型怎么知道字段怎么写

`tutor_scene_guide` 是配套的说明书工具：不传参数返回九种类型的选型指南与步骤写法约定，传 `kind` 返回该类型**全部对象类型 + 逐字段说明 + 一份可直接改的真实示例**。模型第一次画某类图前查一次即可。

### 渲染与安全

演示跑在 `<iframe sandbox="allow-scripts">` 里（不透明源，读不到宿主页面），文档自带 CSP：允许内联脚本/样式与固定 CDN 白名单，`connect-src` 只留 `blob:/data:`——**帧内无法联网**，也禁止嵌套框架与表单提交。所以渲染引擎完全离线自足（不依赖 three.js 之类的 CDN 库，3D 是自带的画家算法渲染器，canvas 2D 投影，无 WebGL 兼容性问题）。

文档从 `GET /api/highschool-tutor/frame.html` 取，**完全静态**（不插值任何场景数据）：整页只取一次，所有演示 iframe 共用同一份 srcdoc；场景数据靠 `postMessage` 送进去，换题、跳步都不重建 iframe。宿主主题令牌（`--dsw-alias-*`）会被解析后桥接成帧内的 `--hst-*` 变量，跟随明暗主题切换，注入值有白名单过滤。

## 复习算法

```
again  ease −0.25，lapses+1，20 分钟后当天重练
hard   ease −0.10，停在当前阶梯，间隔取本档 × 0.6
good   前进一档，间隔取本档标称值 × (ease / 2.5)
easy   ease +0.15，跳两档，间隔再 × 1.3
```

阶梯末档之后按 ease 指数增长，上限 240 天。单卡**掌握度** = 间隔长度 60% + ease 20% + 正确率 20% − 遗忘次数 × 4。**薄弱知识点**按「学科 + 知识点」聚合，综合正确率、遗忘次数与掌握度排序。

## 导入格式

**① Markdown 问答块**（最自由）

```markdown
## 化学            ← 标题里出现学科名 → 切换当前学科
### 化学平衡        ← 三级标题 → 当前知识点
Q: 勒夏特列原理如何表述？
A: 平衡向减弱这种改变的方向移动
解析: 催化剂只改变速率，不移动平衡
#必背 #易错
---
```

前缀兼容 `Q/问/题/题干/正面/front`、`A/答/答案/背面/back`、`解析/解答/分析`，`>` 引用行也会进解析；`---` 分隔卡片。

**② Markdown 表格 / ③ CSV**：表头可用中文（`学科,知识点,题干,答案,解析,难度,标签,来源,年级`）；无表头时按「题干, 答案, 解析, 标签」。

**④ Anki TSV**：忽略 `#separator:` 等注释行，清洗 HTML（`<br>` → 换行），无表头时按 Anki 惯例「正面, 背面, 标签」。

```bash
node scripts/frame-smoke.mjs   # 演示引擎：拼接接缝、13 份场景逐步渲染、步骤语义、交互、消息协议、独立窗口实跑（120 项）
```

三个脚本零依赖：host 测试写在系统临时目录并自动清理；client 测试用最小 window/document 桩加载浏览器包，并用 `react-dom/server` 渲染各标签页；引擎测试用一套**假 canvas 把每次绘制调用录下来再断言**——这样能抓到「NaN 坐标传进 canvas」「某一步画空了」这类截图也看不出来的问题。

`scripts/preview.mjs` 生成的预览是完全独立的 HTML（引擎内联、场景内联、不依赖 DSH 也不联网），用来改完引擎后肉眼确认，或者不装插件也能演示这套东西能画什么。

```
lib/frame/00-core.browser.js    表达式求值（自写解析器，不用 eval）、2D 画笔、3D 投影
lib/frame/10-scene2d.browser.js plot2d / chart2d / mech2d / circuit / diagram2d
lib/frame/20-scene3d.browser.js geom3d（含截面求交）/ molecule3d（VSEPR）/ lattice3d / globe3d
lib/frame/30-shell.browser.js   步骤时间轴、播放控制、拖拽缩放、父子消息协议

scripts/showcase.mjs  生成 docs/ 演示画廊（可挂 GitHub Pages）
scripts/preview.mjs   生成 .preview/ 单文件预览（引擎内联，方便单独分享）
docs/                 已生成的画廊（提交入库）
```

`*.browser.js` 是**浏览器脚本而不是 ESM 模块**：host 侧按文件名顺序读出来拼成一整段注入 iframe。这样既零构建（改完刷新即生效——`frameRuntime()` 按文件 mtime 失效，编辑引擎不必重启 host），又能在 node 里用 `new Function` 加载后直接单测纯逻辑——表达式求值、截面求交、VSEPR 键角、晶胞微粒数都是这么测的。

两条约束值得记住，都是踩过的坑：

1. **每个 `*.browser.js` 必须以分号收尾**，拼接时也要在段间插分号。这些文件都是 `})(…)` 形式的 IIFE，少一个分号就踩 ASI 陷阱——下一个文件开头的 `(function (NS) {…})` 会被解析成对上一段返回值的调用，整段脚本抛 `TypeError`，结果只有第一个文件生效（表现为卡片有壳子、画布空白、`mount` 不存在）。`frame-smoke.mjs` 有 6 项专门守这一条，包括「故意用裸换行拼接也必须能跑」。
2. **引擎测试必须加载拼接后的整段源码**，而不是逐文件加载。曾经因为测试逐文件 `new Function`、生产整段拼接，上面那个 bug 在 91 项全绿的情况下溜进了生产——测试没有镜像生产的加载路径，就等于没测。
